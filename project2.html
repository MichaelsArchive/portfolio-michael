Ninja Run - Game Design

YEAR: 2026 · CLIENT: CMD Breda · DISCIPLINE: Creative Technology · TOOLS: Blender, Unity and Visual Studio Code

A fast-paced Unity game that combines responsive controls, combat and progressive difficulty in a cyberpunk setting. Players guide a ninja through the city, collecting coins while deflecting or avoiding incoming shurikens. The increasing pace creates a simple but engaging gameplay loop focused on timing, interaction and visual feedback.

Additional Visuals

Process & Reflection

I started by exploring the visual direction and atmosphere of the game, before building the core gameplay in Unity.

I focused on responsive movement, clear interactions and a consistent cyberpunk environment.

This project taught me how visual design, animation, UI and game mechanics can work together to create an interactive experience.
